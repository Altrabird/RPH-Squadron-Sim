# RPH Mobile Suit Squadron

Three.js simulation of the 5-bot weekly eRPH pipeline (RPT reader, RPH planner, Sheet filler, reviewer with Telegram approval, Classroom sender), played on real Minggu 32 data.

Live: https://altrabird.github.io/RPH-Squadron-Sim/

Open `index.html` (it loads `w32.js` next to it), press LAUNCH, and tap Lulus on the phone when RX-04 asks.
